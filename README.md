# VT-Zack-2.0

A digital-first executive functioning tutoring experience built around Zach's next developmental arc: productive struggle, flexible problem solving, growing independence, and second-grade readiness.

## Current build

### Mission 01: New Doesn't Mean Impossible
A continuous Challenge Lab experience containing:

- Unknown Box diagnostic
- LOOK → THINK → TRY → CHECK toolbox
- upgraded Turtle reset tool
- digital Creature Rescue design challenge + curveball
- reading-for-a-purpose inference challenge
- classroom directions contradiction challenge
- digital movement/reset moment
- digital tower build + earthquake test
- strategy duel with changing information
- creator mode where Zach designs the challenge
- mixed Final Boss
- short lab report and second-grade cliffhanger

## Design principles

- Fully digital unless explicitly changed later
- Appealing to an advanced incoming second grader without feeling babyish
- Novelty and cognitive challenge over passive entertainment
- Executive functioning demands embedded into authentic problems
- Familiar routines retained as tools, not as the whole lesson
- Less adult prompting over time
- Mistakes produce information
- Appropriate help-seeking is treated as a strength

## Running

This is a static site. Open `index.html` locally or serve through GitHub Pages.

Progress is saved in browser `localStorage` so a refresh does not erase the current mission state.
